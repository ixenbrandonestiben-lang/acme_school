# Guía de Clonación del Proyecto

> [!NOTE]
> Esta guía asume que tienes [Git](https://git-scm.com/) instalado en tu sistema.

## 1. Clonar el Repositorio

Abre tu terminal (o consola de comandos) y ejecuta el siguiente comando:

```bash
git clone https://github.com/TU_USUARIO/acme_school.git
```

## 2. Entrar al Directorio del Proyecto

Una vez descargado, muévete a la carpeta del proyecto:

```bash
cd acme_school
```

## 3. Instalar Dependencias

Asegúrate de tener Node.js instalado. Para descargar todas las librerías necesarias (como Inquirer, Chalk, MySQL2), ejecuta:

```bash
npm install
```

## 4. Siguientes Pasos

Una vez instaladas las dependencias, dirígete a la [Guía de Configuración de Base de Datos](./configuracion_bd.md) para continuar con la preparación del entorno.
